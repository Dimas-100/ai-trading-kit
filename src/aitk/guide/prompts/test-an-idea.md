# Test a trading idea with me

Use the practice lab tools. I want to test this idea: **[describe your idea here in plain words]**

1. Pick the built-in strategy closest to my idea, or say that none fits.
2. Check what price history is available for **[symbol]**. If it is demo prices, tell me.
3. Run the backtest and report: total return, buy and hold return, largest drop, number of trades.
4. Tell me honestly whether it beat simply buying and holding, and how much the result can be trusted
   given the number of trades.
5. Suggest one other symbol to repeat the test on, and run it.

Do not present any result as a reason to trade.
